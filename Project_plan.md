# Main idea of the project
This project aims to read MRI scans, preprocess them, create a deep learning model that will learn to identify the location of a tumor in the scan if there is one and sround the tumor with a rectangle.

# What I want you to do
- Download the dataset to this project folder (also any meta data on the dataset)
- Preprocess the data
- Build a model using pytorch
- Split to train validate and test sets
- Train the model (make sure there are prints on the training process so I know whats happening)
- Test the model and show the test scans with the border that the model created around the tumor
